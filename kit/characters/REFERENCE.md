# Character references (2026-11-23)

Gemini made 8-pose reference sheets for Marc, Otto, the SPIKE cactus and the Cage padlock (stylised 3D CG, for
Flow / Veo prompts). They are not in this repo (AI images); this note records how they compare with the kit.

| character | sheet vs kit | verdict |
|---|---|---|
| Otto | mustard cardigan, tuft hair, round glasses, cactus pin, red pocket notebook, slate trousers: same as `otto.json` (sheet greens/reds use the palette values #88D445 / #E5484D, the kit uses #4f9a3c / #e8473b) | match; kit unchanged |
| Marc | charcoal wool overshirt, off-white tee, round black glasses, stubble, cactus collar pin: same as `marc.json` and the Flow host. The sheet's overshirt is darker (#232126 vs #4d5058) | match; keep the kit's lighter charcoal (reads better as a flat card) |
| SPIKE cactus | green kawaii saguaro, oval eyes, U smile: same character as `buddy.ts`. Extra poses with props (doctor coat, shield, magnifier) | match; use only the props that illustrate a real result (no "Gatekeeper" shield: that project does not exist) |
| Cage padlock | dark rounded body, orange shackle, glowing eyes, bar mark: matches the `padlock` cameo | match |

Style difference: the sheets are rounded 3D CG; oddly-shorts draws flat ink-outlined cards in a 3D world. Use the
sheets for AI video tools (Flow, Veo) and the JSON specs for oddly-shorts; never mix the two styles in one video.
